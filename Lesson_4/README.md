# Матеріали уроку 4

## Мета уроку
- Генерація блоків на полі та їх відображення.
- Обробка колізій з межами поля та іншими блоками.
- фіксація блоків на полі.
- ротація блоків.

> [!NOTE]
> 1. У презентації основної частини уроку у коді (на слайдах 10 та 16) наведена функція `gb.getKey()` яка є частиною бібліотеки `GameBoy.h`, яка не враховує специфіку вашого проекту.
> У коді Вашого проекту є функція `getKey()`, що є вашою власною реалізацією для обробки натискань на сенсорному екрані. Вона була створена вами раніше протягом уроків замість `gb.getKey()`.
> Тому, щоб код працював правильно, потрібно замінити `gb.getKey()` на `getKey()`.
> 
> 2. У презентації основної частини уроку у коді (на слайді 16) наведена функція `void makeMove()`. В цій функції є рядки, які відповідають за поворот фігури, які приводять к нестабільній поведінці (при `rot == 3` можливо `array overflow` - звертання за межи масиву). 

Тому рекомендується замінити код функції `makeMove()` на наступний, який враховує ці нюанси та забезпечує стабільну роботу гри:

```cpp
void makeMove(){
  if (getKey() == 4){
    if(!gb.checkBlockCollision(gb.block[rot], x - 1, y)){ 
      x--;
  }}
  if (getKey() == 5){
    if(!gb.checkBlockCollision(gb.block[rot], x + 1, y)){
      x++;
  }}
  if (getKey() == 1)
    if (!gb.checkBlockCollision(gb.block[(rot + 1) % 4], x, y)) 
      rot = (rot + 1) % 4;  
}
```
